# feeds.txt のサンプル
#
# 書式
#   - 1行に1URLを書きます。
#   - URLの後ろに空白かタブを入れて、表示名を書けます(省略できます)。
#   - 表示名は、news.mdの見出しになります。省略すると、フィード自身のタイトルが使われます。
#   - #で始まる行は、コメントとして無視されます。
#
# 順序
#   - 同じ記事が複数のフィードにある場合は、上に書いたフィードの記事が残ります。
#   - 他のフィードの記事を含む総合フィードは、最後に書きます。
