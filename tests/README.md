RSS新着収集スクリプトのテスト
=============================

概要
-------------------------

`tests/run_tests.sh`は、Node.js版、PHP版、Python版を同じローカルAtomフィードに対して並列実行します。
各版は別々のフィード設定、DB、出力ファイル、複製ディレクトリを使います。

必要な環境
-------------------------

- Node.js 24以上と`zx`
- PHP 8.2以上
- Python 3.11以上
- `curl`
- 各版の依存パッケージ(`node_modules`、`vendor`、`python-vendor`)が導入済みであること

実行方法
-------------------------

リポジトリのルートで実行します。

```bash
bash tests/run_tests.sh
```

確認内容
-------------------------

- 1回目は直近の記事だけが新着になり、古い記事はDBにだけ登録されること
- 2回目は新着0件になること
- 各版のDBに記事2件、フィード1件が登録されること
- 各版の複製ディレクトリに1ファイルだけできること
- パスと取得日時を除いて、3版の`news.md`が一致すること

個別実行
-------------------------

`tests/news_test.mjs`、`tests/news_test.php`、`tests/news_test.py`は、`TEST_ROOT`と`FEED_URL`を設定すると個別に実行できます。
通常は`tests/run_tests.sh`を使ってください。

一時ファイル
-------------------------

テスト用のフィード、DB、出力、複製は一時ディレクトリに作成し、終了時に削除します。
